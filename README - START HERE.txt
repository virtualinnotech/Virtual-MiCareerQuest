MiCareerQuest DEV
=================

HOW TO START THE GAME

1. Double-click: Click to run.command
2. Terminal will open automatically.
3. Your browser will open to: http://localhost:8000/
4. Keep the Terminal window open while you test the game.
5. When finished, go back to Terminal and press Control+C.

FIRST-TIME macOS NOTE

Because this is a downloaded command file, macOS may block it the first time.
If that happens:

- Right-click "Click to run.command"
- Choose Open
- Click Open again

You should only need to do that once.

DEVELOPMENT WORKFLOW

- index.html is the easy-to-launch development build.
- Source code lives in the venue/source and studio/source folders.
- Future changes can be made to the project instead of creating a brand-new giant file every time.
- After a source-code change is rebuilt, refresh the browser to test it.

TIP

You do NOT need to type "python3 -m http.server 8000" manually anymore.
